# 🔐 Password Strength Checker

A simple Python-based Password Strength Checker that analyzes a password and provides a strength rating based on different security criteria.

## 📌 Features

- Checks password length
- Checks for lowercase letters
- Checks for uppercase letters
- Checks for numbers
- Checks for special characters
- Provides a password strength rating
- Gives suggestions for improving weak passwords
- Simple graphical user interface using Tkinter

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Regular Expressions (Regex)
- Kali Linux
- Git & GitHub
